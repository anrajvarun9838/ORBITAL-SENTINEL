About Orbital Sentinel

Orbital Sentinel is an AI-assisted project focused on understanding and monitoring objects in Earth orbit. It explores how orbital data can be processed to identify close approaches and help prioritize potential collision risks.

The project combines basic orbital mechanics, machine learning, and data visualization to present complex orbital information in a simpler and more understandable way.

The goal is to demonstrate how AI and data-driven techniques can support Space Situational Awareness and contribute to safer and more sustainable use of the space environment.
